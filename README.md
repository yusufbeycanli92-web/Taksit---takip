# Taksit Takip

Offline Android/Flutter taksit takip uygulaması.

## Özellikler
- Müşteri, telefon ve plaka kaydı
- Toplam borç, aylık taksit ve ödeme günü
- Ödeme ekleme ve ödeme geçmişi
- Kalan borcun otomatik hesaplanması
- İsim/plaka/telefon ile arama
- SQLite ile cihazda offline veri saklama

## Çalıştırma
1. Flutter SDK ve Android Studio kurun.
2. Bu klasörde terminal açın.
3. `flutter pub get`
4. `flutter run`

## APK oluşturma
`flutter build apk --release`

APK: `build/app/outputs/flutter-apk/app-release.apk`
